Complete the Game

I created a game called “Complete The Game” and it is a “ball” catching game that intentionally irritates the player by making the progression take longer or be more irritable to complete than expected. Aside from the mechanics in the game as we were making it in class, some of the things I included are a timer, a “pop up” screen, and a textbox for user input. The game initially comes off as achievable and simple to play, especially considering the simplicity of the game’s appearance. However, as the game progresses the “ball” becomes more and more complicated to catch. This game is not simply about being “annoying” to play, but rather a thinking piece that makes users attempt to understand how the game works. This is intended to be similar to a puzzle game by making the player attempt every possible combination to find the right answer. Overall, I aimed to make a game that both irritates the player but also makes them think about how the level functions.
