First Responder Healthcare Discount


The first project for this class was done in Adobe Illustrator. This tested the ability to use the pen tool and other tools such as the path finder feature. The main goal was to create some form of symbol, in which I settled on creating reaction images of the Pokémon characters gardevoir, sylveon, and alcremie.



Postcards


The second project for this class involved creating postcards utilizing various Adobe Illustrator tools such as the pen tool, recoloring tools, as well as testing some understanding of composition and color schemes.
